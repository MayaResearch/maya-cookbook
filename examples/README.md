## Streaming and cancellation

**[Open the streaming example →](streaming-tts/README.md)**

Learn how to receive PCM audio progressively, cancel a turn and reuse the connection. Needs only a Maya key. The CLI saves a WAV; real-time playback is supplied by your application.

## A voice agent from scratch

**[Open the from-scratch example →](voice-agent-from-scratch/README.md)**

Follow one turn through microphone/file input, Soniox, OpenRouter and Maya. Needs three provider keys. This deliberately waits for recording to finish before answering; it is not a production conversational agent.
