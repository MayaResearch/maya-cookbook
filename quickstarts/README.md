# Generate your first speech file

[Cookbook home](../README.md) · [All docs](../docs/README.md)

All three options turn text into a WAV. **Choose one. A Maya API key is enough.**

## Python · simplest start

**[Follow the Python guide →](python/README.md)**

Python 3.12+, no extra Python packages. Choose this if you just want your first working request.

## TypeScript · Node applications

**[Follow the TypeScript guide →](typescript/README.md)**

Server-side Node, with pinned dependencies. Never put the key in browser JavaScript.

## curl · inspect an HTTP request

**[Follow the curl guide →](curl/README.md)**

Uses curl and a small Python helper to validate audio and create the WAV.
